# sample_reports/ 占位说明

本目录在**公开发布的版本中刻意留空**，以避免泄露作者本人的真实聊天数据。

在原作者本机环境中，这里存放 9 份真实产出样例（四维 / 深度 / 转型 / 人脉 / 知识 / 沟通风格 / 项目漏斗 / 自我认知 / 私域审计的 md + 图表），用于展示各脚本输出的样子。

**其他人安装本技能后：**
- 请用自己的 `output/` 产物参考，或运行各分析脚本生成属于你自己的样例；
- 切勿将含真名的分析文件（network / knowledge / transcript）上传网盘或对外分享；
- 对外内容（如文章）输出前必须脱敏（微信号、手机号、联系人真名、公司 / 学校名）。

详见仓库根目录 `SKILL.md` 的「样例报告」与「隐私红线」两节。
